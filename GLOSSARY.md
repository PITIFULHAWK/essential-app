# Essential Space

A distraction-free focus, DSA tracker, and habit enforcement application built with Nothing OS design principles.

## Language

**DSA Question**:
A data structures and algorithms challenge with a difficulty rating, platform name, and milestone checklists. Primary platforms include LeetCode, Codeforces, and TUF (TakeUForward).
_Avoid_: LeetCode problem, puzzle

**TUF (TakeUForward)**:
The DSA learning platform and problem index curated by Striver (TUF+).
_Avoid_: Striver sheet, TUF site

**Codeforces**:
The competitive programming contest and problem platform used in bootcamp assignments.
_Avoid_: CF, contest problem

**Milestone Checklist**:
A breakdown of the execution stages required to solve a single DSA Question without solution spoilers.
_Avoid_: Subtask, subproblem

**Inactivity Nudge**:
A high-priority periodic system notification dispatched after 15 minutes of detected inactivity.
_Avoid_: Reminder, ping, alert

**Snooze**:
A user-directed silence window applied to Inactivity Nudges for a specified duration.
_Avoid_: Mute, sleep, pause

**Course Tracker**:
A progress monitor for structured online courses tracking completed modules against total modules.
_Avoid_: Tutorial tracker, class list

**Job Pipeline**:
A sequential tracking register for employment applications advancing through defined recruitment stages.
_Avoid_: Job list, application spreadsheet

**Nothing Aesthetic**:
A distraction-free design language composed of AMOLED pure black (#000000), 5x7 dot-matrix typography, monochrome surfaces, and signature red accents (#D71921).
_Avoid_: Dark theme, minimal skin

**Key Pool**:
A collection of API keys associated with a single provider (or across multiple accounts) rotated via round-robin scheduling with automatic rate-limit cooldown and failover.
_Avoid_: Key list, API switcher

**Agent Action (Tool Call)**:
A structured executable domain operation emitted by the AI agent to mutate application state (e.g. creating problems, completing milestones, adjusting course modules, or applying snoozes) without manual UI navigation.
_Avoid_: Function call, bot command

**Episodic Context Buffer**:
A token-compact chronological ledger summarizing the preceding 72 hours of problem attempts, streak logs, and course milestones to ground the agent while minimizing token consumption.
_Avoid_: Chat history, message log

**Agentic Nudge**:
An Inactivity Nudge whose notification copy and suggested actions are dynamically synthesized from the user's currently active problem and recent milestone progress.
_Avoid_: Smart reminder, AI ping

**Agent Proposal Card**:
An interactive review surface presenting the agent's planned domain mutations (e.g. extracted problem attributes, milestone checklists, status updates), enabling the user to confirm, cancel, or append custom instructions before changes commit to SQLite.
_Avoid_: Confirmation dialog, confirmation popup

**Agentic Poke**:
A proactive background intervention triggered when inactivity surpasses 60 minutes without an excused reason, using a token-minimal digest of the last 2-3 completed tasks to deliver creative motivation, witty roasting, or recommended next steps.
_Avoid_: Nag message, spam alert

**Escalating Brutality Engine**:
A progressive intervention mechanism that dynamically scales the intensity of Agentic Pokes based on elapsed unexcused inactivity, transitioning from philosophical and cinematic quotes at 1 hour to sharp, unfiltered reality checks after 2–3 hours.
_Avoid_: Notification timer, nag scheduler

**Agent Pipeline**:
The core operational pipeline of the application through which all user additions (DSA challenges, bootcamp chapters, job applications) are ingested, analyzed with 3-day episodic context, and decomposed into structured milestone checklists prior to operator confirmation.
_Avoid_: Form handler, input parser

**Excused Snooze**:
A silence window initiated with an explicit duration and reason (e.g. "college exams for 2 days", "cooking for 45m"), suppressing all agentic pokes until the window expires.
_Avoid_: Custom mute, holiday mode
